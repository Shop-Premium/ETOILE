ÉTOILE — CATÁLOGO V2 EDITABLE

1. Abre admin.html para administrar el inventario.
2. Puedes agregar, editar, eliminar y cambiar el estado de cada producto.
3. Estados: Disponible, Próximamente en llegar y Agotado.
4. Puedes usar una URL de imagen o subir una foto directamente desde el computador; la foto se comprime automáticamente.
5. Exportar catálogo crea etoile-catalogo-backup.json como copia de seguridad.
6. Importar catálogo recupera una copia .json.
7. La tienda index.html lee el mismo catálogo guardado en el navegador. Si admin.html e index.html están abiertos en el mismo navegador/origen, los cambios se sincronizan y la tienda se actualiza automáticamente.
8. Para publicar la tienda en Internet y permitir que los cambios hechos desde el celular se reflejen a todos los visitantes, hace falta conectar el panel a una base de datos/almacenamiento en la nube. Ese será el siguiente paso.
